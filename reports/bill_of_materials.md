## 2. 포트·케이블·통신 규격 호환표

* **Pixhawk 2.4.8 -> Matek 3901-L0X**: I2C (또는 UART) 및 Telem 포트 사용 (점퍼 케이블 결선 필요)
* **Pixhawk 2.4.8 -> 수신기**: RC IN 포트에 PWM/SBUS 케이블 연결
* **Pixhawk 2.4.8 -> Jetson**: TELEM2 -> UART (MAVLink) - FTDI 어댑터 또는 점퍼 케이블 직결
* **Jetson -> RealSense**: USB 3.0 (Type-A to Type-C) - 카메라 기본 케이블 사용
* **Jetson 전원**: 12V UBEC -> Jetson DC Barrel Jack (5.5x2.1mm) 납땜 또는 어댑터 필요

## 3. 전원 계통도 (F450 기반)
```text
[ 4S 5000mAh 배터리 (14.8V) ]
  ├──> [ F450 하판 전원 분배 보드 (납땜) ] ──> [ ESC / 모터 4개 ]
  ├──> [ Pixhawk Power Module ] ──> [ Pixhawk 2.4.8 (5V) ] ──> [ 3901-L0X, 수신기 ]
  └──> [ 12V 5A UBEC (납땜) ] ──> [ Jetson Orin Nano (12V) ] ──> [ RealSense D435i (USB) ]
```
*주의사항*: Jetson 전원을 절대 Pixhawk나 F450 전원 보드에서 5V로 바로 뽑지 마세요. 반드시 배터리 단자에서 12V UBEC를 거쳐 Jetson의 배럴 잭으로 연결해야 합니다.

## 4. 중량 및 비행시간 계산표
* F450 프레임 및 모터/ESC 세트: ~0.8kg
* 배터리 4S 5000mAh: ~0.45kg
* Jetson Orin Nano + 방열판: ~0.25kg
* RealSense D435i: ~0.07kg
* 기타 모듈 및 배선: ~0.1kg
* **총 이륙 중량 예상치: 약 1.67kg**
* F450 프레임의 권장 이륙 중량은 1.5kg ~ 2.0kg 이내이므로 실내 호버링 및 전술 정찰 비행에 무리가 없습니다. 예상 비행시간 약 12~15분.
